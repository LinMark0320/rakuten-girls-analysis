# 0003. 收錄成員跨隊客串卡，並以 squad_brand 標記來源品牌

## Context

爬蟲關鍵字放寬為「{member} 卡」後，撈到不少標題掛著其他啦啦隊/應援團品牌（慕獅女孩
Muse Girls、桃氣女孩 Peach Girls、臺北伊斯特 Tokki Cutie）、卻同樣命中我們 27 位
成員別名的商品。逐一查證後確認：這些成員本人確實常態跨隊接案（棒球/籃球/排球多棲），
標題撞到的是同一個真人，不是同名不同人——唯一例外是「笑笑」對到「中信兄弟 passion
sisters」，查證時間線後確認是撞名的不同人。另外也發現「Lamigirls／Lamigo」是樂天桃猿
2020 年由 Rakuten 冠名前的舊隊名，同一批成員、同一支隊伍的歷史資料。

## Decision

跨隊客串卡與 Lamigirls 舊史料一律收錄，計入成員本人的真實市場行情；「passion
sisters」對應的「笑笑」則刻意排除（已知撞名不同人）。為避免使用者把跨隊客串卡誤認為
樂天女孩本隊卡，新增 `squad_brand` 欄位，前端在非本隊卡的成員名旁加一個小標籤區分。

## Considered Options

原本考慮建一份「其他啦啦隊品牌」黑名單直接排除撞名候選，但這樣會連同真實的跨隊客串
資料一起濾掉——查證後確認多數撞名案例其實是同一人跨隊，改用白名單（收錄已知品牌）
搭配 `squad_brand` 標記，比黑名單排除更符合實際情況。

## Consequences

- `crawler/yahoo_scanner.py` 的 `_GROUP_ANCHOR_TERMS` 白名單需要持續維護：之後發現新的
  跨隊品牌要手動加進去，否則會被既有的「標題需含團名關鍵字」規則擋掉。
- 「各平台類似商品」等彙總表格會把跨隊客串卡跟本隊卡的最高價放在一起比較；使用者
  需要留意 `squad_brand` 標籤，不能直接假設某成員的最高成交價都是樂天女孩本隊卡。
